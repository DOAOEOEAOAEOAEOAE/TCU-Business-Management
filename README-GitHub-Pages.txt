GitHub Pages flat upload
========================

Extract this ZIP. Upload index.html and every image/PDF file beside it directly to the root of the GitHub repository that publishes the site.

This package uses flat relative filenames. Do not create or rename an assets folder. Keep the filenames exactly as shown and upload the files together.

The campus carousel uses home-SP04-optimized.jpg, created from the requested home-SP04.png, and home-SP05-optimized.jpg, created from the requested home-SP05.jpg. These smaller copies keep the same photos while loading faster. Keep both optimized files beside index.html when publishing. The original photos are included as source copies.
