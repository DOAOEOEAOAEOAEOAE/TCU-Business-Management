GitHub Pages flat upload
========================

Extract this ZIP. Upload index.html and every image/PDF file beside it directly to the root of the GitHub repository that publishes the site.

This package uses flat relative filenames. Do not create or rename an assets folder. Keep each filename exactly as shown. Upload the files together; if GitHub asks to replace existing files, the replacement faculty portraits and Tzu Chi University logo match the current project files.

The latest homepage uses home-SP04.webp and home-SP05.webp for campus slides 4 and 5. Upload both exact filenames beside index.html; uploading only the older SP04.png or SP05.jpg files will not satisfy the current page paths.
