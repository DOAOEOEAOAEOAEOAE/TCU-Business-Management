GitHub Pages site files
=======================

Copy index.html and the complete lowercase assets/ folder to the root of the GitHub repository that publishes the site.

Required layout:
  index.html
  assets/
    brand/
    career/
    faculty/
    home/
    news/

Do not upload only index.html. GitHub Pages is case-sensitive, so keep the folder and file names exactly as shown. After committing the files, allow GitHub Pages to rebuild the site.
